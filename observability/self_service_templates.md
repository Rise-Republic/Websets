# Self-Service Templates for Observability

This document describes available templates for traces, SLOs, dashboards, and alerts.

## Templates

- OpenTelemetry instrumentation (Python, Node)
- JSON logger with trace ID
- Prometheus metrics endpoint
- Grafana dashboard JSON
- Prometheus alert rule YAML
- SLO definition JSON
- Runbook Markdown

## Usage

Copy the relevant template from the observability directory and customize for your service. Submit changes via peer review workflow.
