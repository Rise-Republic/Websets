# Observability Foundation

This directory contains configuration, automation, and documentation for distributed tracing, logging, metrics, alerting, and SLO governance across all platform services.

## Components
- Distributed Tracing (OpenTelemetry, Tempo/Jaeger)
- Structured Audit Logging (ELK/OpenSearch)
- Metrics & Dashboarding (Prometheus, Grafana)
- Alerting (Prometheus Alertmanager, PagerDuty/Slack)
- SLO/SLI Governance (Grafana, Backstage)
- Config-as-Code, RBAC, Compliance Automation

See subfolders for setup, templates, and scripts.
