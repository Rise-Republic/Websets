# Security Policy

If you believe you have found a vulnerability, please report it through GitHub Issues using the security template, or email security@websets.example.com.

## Supported Versions

Only the latest minor release is supported with security patches.

## Reporting a Vulnerability

1. Create an issue using the **Security report** template.
2. Provide steps to reproduce and any relevant logs.
3. Allow 90 days for investigation and remediation before public disclosure.
